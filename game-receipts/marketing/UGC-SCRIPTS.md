# Game Receipts — AI UGC talking-head spots

Recipe from the holdr work (see memory `holdr-ugc-marketing-studio`): Nano Banana Pro start frame with the person already composed → `kling3_0 --mode pro --duration 10 --aspect_ratio 9:16 --sound on --start-image <frame>` with the spoken line in quotes (native voice + lip-sync, the best an AI face gets) → finish only (no slowdown, no re-voice, no re-sync, no heavy humanize).

Structure of each finished ad (~20 s): **talking head 10 s → real app screen footage 7–8 s → Game Receipts end card 2 s.** The creator never holds a readable phone screen (AI garbles UI text) — the real app footage carries the product.

Rules: no team logos, no real jerseys (plain or blank tees/hoodies), no real athlete likeness. Scripts carry fillers and a false start — perfect grammar is the loudest tell. Post with the AI-generated label on (TikTok toggle, Meta "AI info", YouTube altered-content). Never present as a real customer review.
